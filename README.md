🏝️ Treasure Island — Python Adventure Game

Welcome to Treasure Island, a simple text-based adventure game built with Python. Your mission is to find the hidden treasure by making the right decisions at every stage of the journey.

One wrong choice can end your adventure. Choose wisely!


🎮 Game Overview

The game begins with an ASCII-art treasure map and takes the player through a series of interactive choices.

Choose your direction: Go left or right.

Cross the sea: Decide whether to swim or wait for a boat.

Choose a door: Pick between yellow, blue, and green doors.

Find the treasure: Make the correct choices to win the game!


✨ Features

ASCII-art treasure map displayed in the terminal

Interactive gameplay using user input

Case-insensitive choices using Python's lower() method

Branching storylines with conditional statements

Multiple endings, including victory and game over

Beginner-friendly Python code


🛠️ Technologies Used

Language: Python 3

Concepts: print(), input(), strings, if, elif, else, and nested conditional statements


🚀 How to Run

Install Python 3 on your computer.

Download or clone this repository.

Open a terminal in the project folder.

Run the following command:

python main.py

If your system uses python3, run:

python3 main.py

Follow the instructions displayed in the terminal and try to find the treasure!

Make sure the Python filename matches the filename used in your command.
